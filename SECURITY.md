# Security policy

hadzar handles private schedules, notes, messages, and commitments. Please do not report a vulnerability in a public issue or include real account data in a report.

Use GitHub's private security advisory flow for `ikooq/hadzar`. If private advisories are unavailable, contact the maintainer through the [ikooq GitHub profile](https://github.com/ikooq) and include only the minimum reproduction details needed to investigate.

The project deliberately uses publishable Supabase credentials in the browser. Never expose a Supabase service-role key, password, session token, or real user data in source, issues, screenshots, or logs.
